# JARVIS Wiki Index

This wiki stores human-readable long-term knowledge for the Hermes-centered JARVIS workflow.

## Sections

- `SCHEMA.md`: ontology-informed LLM Wiki schema, page types, tags, relation types, and operating rules.
- `index.md`: LLM Wiki content catalog across entities, concepts, comparisons, projects, skills, and queries.
- `log.md`: chronological LLM Wiki maintenance log.
- `entities/`: concrete systems, agents, executors, tools, configs, and repositories.
- `concepts/`: reusable operating concepts, policies, lifecycles, and architecture patterns.
- `comparisons/`: side-by-side analyses worth preserving.
- `queries/`: saved answers that would be costly to re-derive.
- `projects/`: project-specific status, architecture, decisions, runbooks.
- `skills/`: skill catalog, lifecycle policy, candidates, and reviews.
- `decisions/`: cross-project architectural and workflow decisions.
- `templates/`: reusable note templates.

## Operating rule

Hermes memory stores compact durable facts. Hermes skills store executable reusable procedures. This ontology-informed LLM Wiki stores human-readable and LLM-readable long-term project knowledge, typed relations, decisions, and conceptual synthesis.
